# Phạm Thị Thùy Trang · Portfolio

A dreamy, Ghibli-inspired personal portfolio. Single file (`index.html`): images are embedded, no build step.

## Publish with GitHub Pages
1. Create a new public repository (e.g. `portfolio`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, then Save.
4. After about a minute the site is live at `https://<your-username>.github.io/portfolio/`.
